**Última atualização: 1º de novembro de 2026.**

Esta política descreve o tratamento de informações relacionado ao site do projeto Terra Vasta, atualmente uma publicação estática hospedada no GitHub Pages. O site não exige conta, não tem formulário de contato nem inscrição em newsletter e não usa ferramentas próprias de análise de audiência ou publicidade.

## Dados de navegação e hospedagem

Para entregar e proteger o site, o GitHub Pages pode registrar e armazenar o endereço IP dos visitantes para fins de segurança. Esse tratamento é realizado pelo GitHub como provedor de hospedagem e segue as [políticas de privacidade do GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Veja também a documentação do GitHub sobre [dados coletados pelo GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

O projeto não instala cookies de análise ou publicidade. A preferência de tema claro ou escuro é salva no armazenamento local do navegador para que a interface possa lembrar a escolha. Essa preferência não é enviada ao site a cada visita e pode ser apagada nas configurações do navegador.

A busca funciona no próprio site, usando arquivos públicos publicados junto com as páginas; não usamos um serviço de busca terceirizado para registrar suas consultas.

## Mensagens de contato

Se você enviar um e-mail para [dragaodebotas.studio@gmail.com](mailto:dragaodebotas.studio@gmail.com), receberemos o endereço de e-mail usado, o nome que você informar e o conteúdo e os anexos que decidir incluir. Usaremos essas informações para responder e acompanhar sua solicitação. Não envie dados sensíveis que não sejam necessários para o assunto.

As mensagens são transmitidas e armazenadas por provedores de e-mail, incluindo o Google, conforme as políticas desses serviços. A correspondência pode ser mantida pelo tempo necessário para tratar o contato e cumprir eventuais obrigações legais. Você pode solicitar acesso, correção ou exclusão das informações enviadas pelo endereço acima, observadas as obrigações aplicáveis.

## Links externos

O site contém links para serviços de terceiros, como GitHub, Ko-fi, Bluesky e X. Ao acessá-los, você passa a usar os serviços desses provedores, que têm suas próprias práticas e políticas de privacidade.

## Alterações e contato

Esta política pode ser atualizada quando as funcionalidades ou práticas do site mudarem. A data da versão vigente aparece no início da página. Se o site passar a usar formulários, newsletter, ferramentas de análise ou outros recursos que tratem dados, esta política será revista para descrevê-los.

Para dúvidas ou solicitações relacionadas à privacidade, escreva para [dragaodebotas.studio@gmail.com](mailto:dragaodebotas.studio@gmail.com).
