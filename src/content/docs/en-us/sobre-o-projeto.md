## About Terra Vasta

Terra Vasta is an independent tabletop role-playing project that brings together a game system and a dark fantasy setting. In Taavira, survival, exploration, tactical combat, and dangerous magic shape stories amid ruins, cosmic decay, and fragile hope.

## About the studio

Dragão de Botas Studio is an independent studio dedicated to creating tabletop RPGs, books, and video games. Terra Vasta is one of the studio’s original projects.
